# Biometric Deepfake Guard

End-to-end facial biometric verification and deepfake detection system built with PyTorch, FaceNet, and Hugging Face Vision Transformers.

## Environment Setup
1. Create and activate a Python 3.11 virtual environment:
   ```bash
   py -3.11 -m venv venv
   .\venv\Scripts\activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the inference verification test:
   ```bash
   python test_inference.py
   ```
